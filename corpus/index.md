- [wiki/sources.md](wiki/sources.md) - The two outside sources Lantern uses since the owner dropped TMDB on 2026-11-04. IMDb's non-commercial data files (title.basics, title.ratings, title.crew; columns, sizes, the \N null marker, daily refresh) for the title pool, and OMDb by IMDb id for each title's details, poster and three scores (1,000 calls a day; its fields and error answers). The terms, read 2026-11-04: IMDb's data for personal, non-commercial use only, with a fixed credit line; OMDb CC BY-NC 4.0. TMDB's place in the history.

- [wiki/suggestions.md](wiki/suggestions.md) - How Lantern ranks suggestions, as built 2026-11-04. Plain arithmetic over the title pool, no model: a taste profile per genre, director and writer from the four ratings (awful -2 to amazing +2), each title's weight spread over its features of a kind (1/√k, so a series' dozens of episode directors don't swamp a film's one) and damped by how often a feature recurs (1/√n); features weighted director 2, writer 1.5, genre 0.5; a nudge for IMDb's rating and votes; at least one liked title must account for 0.5 of the score; the reason is the liked title with the largest share. What it can't do, and how it ran on the real pool.
- [wiki/titles.md](wiki/titles.md) - The title pool, Lantern's own list of films and series built from IMDb's non-commercial files, as built 2026-11-04. What it keeps per title; the types (tvMovie counted as a film) and the 1,000-vote threshold; the first real import (65,732 titles, 32 s, 14.5 MiB, counts at 500/1,000/2,000/5,000 votes); how the import streams the files without keeping them, and the memory fix (sliced strings); how a re-run replaces the pool in one transaction without touching the states; and the credit line IMDb's terms require.
- [wiki/web-app.md](wiki/web-app.md) - What the Lantern page is made of as of 2026-11-11 - the Base UI wrappers under web/src/components/ui/ (RadioGroup, ToggleGroup, Tabs, Button), which widget uses which, the rating page's key guard, where Base UI stops, and the look - Tailwind 4 in one stylesheet, the family's token names with Lantern's values, the type scale, light-dark() colour tokens and the Light / Dark / System switch on data-theme.
